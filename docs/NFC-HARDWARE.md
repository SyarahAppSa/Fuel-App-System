# NFC — المسار الحالي والعتاد المطلوب للاختبار الفعلي

## ما يعمل الآن في النسخة التجريبية
- **قراءة فعلية** عبر Web NFC في متصفح Chrome على Android: زر «مسح عبر NFC» يقرأ الرقم التسلسلي (UID) للشريحة ويرسله للخادم للتحقق.
- **محاكاة واضحة** على أي جهاز (كمبيوتر/آيفون): قائمة «محاكاة قراءة شريحة (عرض)» تختار UID شريحة مسجلة، أو إدخال UID يدويًا. المسار بعد القراءة هو نفسه تمامًا (نفس التحقق الخادمي، نفس السجل، نفس الرفض والأسباب).
- الشريحة تحمل **معرّفًا تقنيًا فقط** (UID)؛ لا يُكتب عليها اسم العميل أو المعدة. الربط بالأصل والسياسات محفوظ في الخادم.

## العتاد المطلوب لاختبار القراءة الفعلية

| البند | المواصفة المقترحة | لماذا |
|---|---|---|
| جوال القراءة | Android 10+ مع NFC وChrome 89+ (مثل Samsung Galaxy A35/A55 أو Google Pixel 7+) | Web NFC مدعوم على Chrome Android فقط |
| جهاز ميداني (اختياري) | جوال/تابلت Android مقوّى IP67 مع NFC (مثل Samsung Galaxy XCover7 أو Zebra TC22) | بيئة المواقع (غبار، حرارة، قفازات) |
| الشريحة — المرحلة الأولى | NTAG215 أو NTAG216، ملصق **مضاد للمعادن (On-Metal / Anti-Metal)** بقطر 25–30 مم، مقاوم للماء IP68، لاصق صناعي 3M مع إمكانية التثبيت ببرشام | أغلب المعدات أسطح معدنية تُضعف القراءة؛ الشريحة العادية لا تُقرأ على المعدن |
| الشريحة — تحقق أعلى (تقييم لاحق) | NTAG 424 DNA (توقيع SUN/SDM مشفّر) مضاد للمعادن | يمنع نسخ UID؛ يحتاج تعديلًا خادميًا للتحقق من التوقيع |
| بديل iOS | iOS لا يدعم Web NFC: تطبيق أصلي (Core NFC) أو قارئ Bluetooth خارجي (مثل ACS ACR1255U-J1) | إن كانت أجهزة الآيفون ضمن الأجهزة الميدانية |

## خطة الاختبار على المعدات الفعلية (الاختبار 10)
1. 20 شريحة On-Metal + جوالان Android مختلفان + جهاز ميداني واحد.
2. التركيب على 5 أصول ممثلة: حفار (هيكل معدني مطلي)، شيول، مولد (غطاء صاج)، مركبة (زجاج/بلاستيك)، خزان ثابت.
3. لكل تركيب: 30 محاولة قراءة، تسجيل نسبة النجاح وزمن القراءة والمسافة (مم) والزاوية، مع قفاز ودون قفاز، في الشمس المباشرة.
4. تجربة الشريحة الموقوفة والمستبدلة والمكررة أثناء انقطاع الشبكة ثم المزامنة.
5. اعتماد فريق السلامة لموضع التركيب (بعيدًا عن فتحة الوقود ومناطق الحرارة والاهتزاز).
6. توثيق مصفوفة التوافق (جهاز × شريحة × سطح) قبل اعتماد المواصفة النهائية.
